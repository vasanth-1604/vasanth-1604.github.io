# Vasanth A — Portfolio

Personal portfolio website built with HTML, Vanilla CSS, and JavaScript.

**Live site:** https://vasanth1602.github.io

## Stack

- Pure HTML + CSS + JavaScript (no frameworks, no build step)
- Google Fonts: Inter + JetBrains Mono
- Formspree for contact form
- GitHub Pages for hosting

## Local Development

Just open `index.html` in a browser. No build step required.

## Assets Required

Place in `assets/` before deploying:
- `resume.pdf` — your resume PDF
- `votesecure.png` — VoteSecure project screenshot
- (Project screenshots from ML Platform and AWS Platform are already copied)

## Deployment (GitHub Pages)

1. Push this folder to a repo named `vasanth1602.github.io`
2. Go to Settings → Pages → Source: Deploy from branch `main`, folder `/root`
3. Site goes live at `https://vasanth1602.github.io`
